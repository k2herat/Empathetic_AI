Распознавание эмоций по лицам — два подхода

В репозитории представлены два Jupyter-ноутбука для классификации выражений лица по 7 эмоциям: злость, отвращение, страх, радость, нейтральное, грусть, удивление.

1. Свёрточная нейросеть (CNN) — cnn-face-reaction-predict.ipynb

Архитектура: собственный CNN с двумя свёрточными блоками, batch‑нормализацией, dropout и полносвязными слоями.
Данные: FER2013 (35 887 изображений), аугментация (отражение, поворот).
Результат: точность на валидации ~64–65%.

2. Vision Transformer (ViT) — facial-expression-recognition-using-vit.ipynb

Модель: дообучение предобученного ViT (Hugging Face).
Данные: объединение AffectNet, FER2013 и MMI (~189 738 изображений), расширенная аугментация.
Результат: точность ~84.3%, также строятся матрица ошибок и отчёт по классам.
Сравнение и использование

ViT значительно превосходит CNN благодаря большему объёму данных и трансферному обучению.
Для запуска требуются: Python 3.8+, PyTorch, Hugging Face Transformers, scikit‑learn, pandas, numpy, matplotlib.
Установка зависимостей: pip install torch torchvision transformers datasets scikit-learn pandas numpy matplotlib seaborn.
