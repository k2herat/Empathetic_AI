Этот проект реализует систему распознавания эмоций в речи на основе глубокого обучения.
Используются три архитектуры: LSTM, BiLSTM и гибридная CNN+BiLSTM.
Для извлечения признаков применяются MFCC (40 коэффициентов) из аудиозаписей датасета RAVDESS.

📁 Данные

Датасет: RAVDESS (8 эмоций: нейтральная, спокойная, счастливая, грустная, злая, испуганная, отвращение, удивлённая).
Аудиофайлы в формате .wav загружаются из папки /kaggle/input/.
Данные разбиты на обучение (80%) и тест (20%).
🧠 Модели

Модель	Описание
LSTM	Однонаправленная рекуррентная сеть с одним слоем.
BiLSTM	Двунаправленная LSTM (2 слоя) – учитывает контекст с обеих сторон.
CNN + BiLSTM	Свёрточный слой (Conv1D) для локальных паттернов + BiLSTM для временной динамики.
Обучение проводится с CrossEntropyLoss, оптимизатором Adam и ранней остановкой (patience=30).
